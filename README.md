## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/simran-portfolio-v3.0.git
```

Move into the project directory:

```bash
cd simran-portfolio-v3.0
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## ⚙️ Available Scripts

### Run development server

```bash
npm run dev
```

### Build production bundle

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

### Run linting

```bash
npm run lint
```

### Deploy to GitHub Pages

```bash
npm run deploy
```

The deployment pipeline automatically:
- Builds the Vite project
- Adds the custom domain configuration
- Publishes the `dist` folder using `gh-pages`

Current deployment configuration:

```json
"predeploy": "npm run build && echo 'sibansal.dev' > dist/CNAME",
"deploy": "gh-pages -d dist"
```

---

## 🌐 Custom Domain Setup

This project is configured for custom domain deployment using:

```txt
sibansal.dev
```

The `CNAME` file is automatically generated during deployment.
